JmEditor 샘플

src/ 의 코어와 UI 를 한 파일로 합친 단독 데모입니다. 라이브러리 없이 contenteditable + Range 로 직접 구현한 코어. 툴바 버튼, Editor/HTML/미리보기 모드 전환, 글자색·배경색, 단축키(Ctrl+B/I/U/Z), 붙여넣기, 이미지 드롭, 「서식」 템플릿·이미지 갤러리·유튜브 삽입, 표(셀 드래그로 범위 선택, 우클릭 → 행/열/병합/정렬 메뉴, 셀 경계 끌어 너비·높이 조절)를 바로 써볼 수 있습니다.
